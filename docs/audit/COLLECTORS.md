# Collectors and external integrations

Audit date: 2026-09-23. Repository: `social-media-ai-agents-v2-main` (package name `sentinel-ai`), branch `transform/pulselens` at commit `ebfe83b`.

Every row below was located by reading the code, not the documentation. "Commercial use permitted" is filled in only where a terms page was fetched during this audit (fetch date 2026-09-23) or where the code itself calls a paid commercial API. Everything else is **UNKNOWN**. UNKNOWN never means "probably fine"; it means nobody has checked.

Legend for the "Passive / active" column:

- **Passive** means the code reads a third party's record about the target and never contacts the target.
- **Active** means packets reach the target, or the code executes on the host it runs on.
- The code's own declared `collectionMode` is quoted where the collector declares one.

## 1. Collector-framework adapters (`src/utils/collectors/`)

These implement the `Collector` contract in [src/utils/collectors/types.ts](../src/utils/collectors/types.ts) and are registered by `registerExistingCollectors()` / `registerExternalCollectors()` / `registerPersonCollectors()`. They are what the OSINT Investigation panel on `/recon`, the job system in `src/utils/osint/jobs.ts` and the orchestrator in `src/utils/osint/orchestrator.ts` run.
